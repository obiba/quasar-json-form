# Rating

<p class="doc-lead">An integer with <code>options.format: "rating"</code> renders a <a href="https://quasar.dev/vue-components/rating">QRating</a>.</p>

Every other option is passed to `QRating`: `max`, `icon`, `iconSelected`, `color`, `size`,
`noReset`... The `hint` is set on the control element itself.
